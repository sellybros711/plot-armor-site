Plot Armor: Games

Covers video-game story spoilers on X until you've finished the game. First up: GTA 6.

Being built

The idea

  • Add a game you're playing, or about to play
  • Posts about it get a "Possible spoiler" cover: story, endings, missions, leaks and trailers
  • "Show anyway" uncovers one post; "I've finished it" stops hiding that game

Plot Armor: Games is still being built, so details may change before it reaches the Chrome Web Store. Like every Plot Armor extension, it will work on your computer with no account and no Plot Armor server.
